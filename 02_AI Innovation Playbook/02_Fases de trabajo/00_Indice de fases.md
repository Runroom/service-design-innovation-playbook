# Índice de fases de trabajo

Las fases ayudan a ordenar el pensamiento y el trabajo durante la formación.

Cada fase se describe con la misma estructura:

* input esperado,
* mentalidades que operan,
* qué se practica,
* técnicas útiles,
* artefactos relacionados,
* resultado útil,
* cómo alimenta la siguiente fase.
